自己动手做一次小盲测

用同一个题目，比较“普通模式”和“技能模式”的回答。这个工具只在你的浏览器里运行，不会上传你粘贴的内容。

这个技能主要用来直接回答问题，不是把一段文字改成另一种腔调的改写器。体验时请让两份回答分别完成同一个任务。

第 1 步：选一个题目

题目覆盖概念解释、数据说明、方案建议、项目沟通、正式通知、客服、日常沟通、情绪回应、叙事、产品文案、招募文案和英译中。

第 2 步：分别问两个 agent

请使用同一个模型和同一个题目，开两个新对话分别问，不要让同一个 agent 在同一段对话里扮演两种角色。

普通模式

不加载本技能

直接把题目发给一个没有加载技能的 agent。

技能模式

加载本技能

在支持技能调用的工具里，可以用下面格式：

$no-english-style-chinese <粘贴这里的题目>

如果你的工具不支持 $，就按它的技能调用方式加载后再提问。

第 3 步：粘贴两份回答

开始后，页面会把两份回答随机变成 A / B，并暂时隐藏来源。

第 4 步：盲评 A / B

评分：1 = 很差，2 = 较差，3 = 一般，4 = 较好，5 = 很好。
